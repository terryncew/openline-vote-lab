# openline-vote-lab

Open-source research infrastructure for cryptographically verifiable voting and independent election auditing.

## Status

Experimental research. This is not certified election software, and it is not a system approved for binding public elections.

## Research goal

Build the primitives and tooling an independent party needs to verify an election result without trusting the system that produced it: tamper-evident records, independent verification, and public auditability.

This repository starts minimal. Engineering, environment configuration, testing, documentation, and the eventual MVP are handled separately.
